## 2025-02-28 - Streamlit Native ARIA Support
**Learning:** Streamlit automatically generates native tooltips and ARIA labels for accessibility when the `help` parameter is provided to its input widgets (such as `st.button`, `st.text_input`, `st.multiselect`, `st.file_uploader`). This makes improving accessibility in Streamlit applications extremely straightforward compared to traditional React/HTML development.
**Action:** Always include the `help` parameter with a descriptive, user-friendly string on all interactive Streamlit widgets to ensure baseline screen reader compatibility and better UX tooltips.
