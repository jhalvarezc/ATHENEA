## 2024-05-18 - Leveraging Native Streamlit Tooltips for Accessibility
**Learning:** Using the `help` parameter natively available in most Streamlit input widgets (like `st.button`, `st.text_input`, `st.file_uploader`, etc.) is an incredibly efficient way to add both visual tooltips and underlying ARIA labels. This drastically improves screen reader compatibility and general usability without requiring any custom CSS or heavy workarounds.
**Action:** Always include a descriptive `help` parameter when creating interactive Streamlit widgets to ensure baseline accessibility and a better user experience for form and action elements.
