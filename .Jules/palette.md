## 2025-02-28 - [Streamlit UX/A11Y] Tooltips & ARIA labels in Streamlit Input Elements
**Learning:** For inputs like `text_input`, `file_uploader`, `button`, and `form_submit_button` in Streamlit, there is limited support to manually modify underlying HTML tags to add custom `aria-label` properties. However, adding the `help` keyword parameter to these elements automatically generates native tooltips and acts dynamically as a descriptive label/tooltip to improve the UX and baseline accessibility of the widget.
**Action:** Use the `help` attribute broadly when building out Streamlit forms to add UX-friendly tooltips to inputs, buttons, and uploaders, ensuring users have additional context on what action will be taken.
