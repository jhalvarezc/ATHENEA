## 2024-03-21 - Streamlit Tooltip & Accessibility Constraints
**Learning:** Streamlit UI components (`st.button`, `st.text_input`, `st.file_uploader`) natively support tooltips and better ARIA-labeling simply by providing the `help` string parameter. In this application, standardizing this parameter makes controls more discoverable and significantly improves screen reader context without adding external UI libraries or messy inline HTML tricks.
**Action:** Always include a brief, descriptive `help="[contextual description]"` when adding or modifying core interactive widgets in Streamlit views (especially forms and file handlers) to ensure consistent UX and accessibility.
